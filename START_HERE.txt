GREYSON'S DISNEY TRIP — PWA FOUNDATION (NOV 2026)
=================================================
This starter adds installable PWA metadata, icons, a service worker, and a
resumable offline download control. It does NOT replace your customized map.
Do not publish Disney artwork unless your permission covers redistribution.

A. ADD NEW FILES TO THE GITHUB DESKTOP PROJECT
---------------------------------------------
Extract this ZIP. Copy these items to the ROOT of your local project (the
folder containing index.html and tiles/):

  manifest.webmanifest
  sw.js
  offline-ui.js
  build_tile_index.py
  icons/ (entire folder, including all 3 PNGs)

B. GENERATE AN EXACT LIST OF YOUR REMAINING TILES
------------------------------------------------
In PowerShell, from inside the project folder:

  py build_tile_index.py

This creates tile-index.json by scanning your ACTUAL remaining tiles. It does
not modify, download or restore any artwork. Regenerate if you ever edit tiles.
Keep tile-index.json in the GitHub commit.

C. MAKE TWO SMALL EDITS TO YOUR EXISTING index.html
--------------------------------------------------
1. In the <head>, directly after the existing theme-color meta tag, paste:

  <link rel="manifest" href="manifest.webmanifest" />
  <link rel="apple-touch-icon" href="icons/apple-touch-icon.png" />
  <meta name="apple-mobile-web-app-capable" content="yes" />
  <meta name="apple-mobile-web-app-title" content="Disney Trip" />
  <meta name="apple-mobile-web-app-status-bar-style" content="default" />

Change the existing theme-color content to #b8cbb0 to match your map background.

2. Near the very bottom, immediately BEFORE </body>, paste:

  <script src="offline-ui.js"></script>

Do NOT replace the rest of index.html. Leave camera settings, tileBounds,
artworkBounds, touch controls, tileLayer etc. as currently configured.

D. PREVIEW ON YOUR WINDOWS COMPUTER
----------------------------------
In your project folder:

  py -m http.server 8000

Open http://localhost:8000/ in Chrome or Edge. Open the "Offline map" panel
in the lower left. On desktop localhost, the service worker should activate,
and the panel should report your remaining tile count from tile-index.json.

On your iPhone, the LAN URL (for example http://192.168.x.x:8000/) remains a
useful map preview, but it CANNOT install a service worker or enable PWA
caching, because it is insecure HTTP. This is expected, not a broken app.

E. COMMIT THROUGH GITHUB DESKTOP
-------------------------------
Check that the changed files are index.html and the added items above.
Commit and push. No changes to the existing tiles should be necessary.

F. HTTPS HOSTING AND IP/PRIVACY DECISION
---------------------------------------
For an installable iPhone PWA and reliable offline testing, the app must be
served over HTTPS. Your GitHub repository was private during review. GitHub
Free Pages only supports public repositories; GitHub Pro supports private
repository sources, but a published Pages site may still be accessible to
the public. Making the repository/site public would distribute copied Disney
map imagery; confirm redistribution rights first. Do not change the repo's
visibility just to get this PWA working.

G. ONCE THE APP IS SERVED OVER HTTPS
-----------------------------------
1. On iPhone Safari, open the HTTPS site.
2. Use Share -> Add to Home Screen -> Add.
3. Open the NEW Home Screen app. This may have separate storage from Safari.
4. Tap "Offline map" -> "Download all tiles". Keep the app in the foreground.
5. When it says all tiles are saved, close and reopen the Home Screen app in
   airplane mode. Verify both the map AND multiple zoom levels work.
6. Repeat the offline test shortly before your trip. iOS may evict caches if
   storage is low; a PWA cannot promise indefinite local storage.

IMPLEMENTATION NOTES
--------------------
- Shell assets: cached at install and updated online.
- Map tiles: cache-first for normal browsing; bulk download saves every path
  in tile-index.json and supports resume. The tile cache survives shell updates.
- Status is verified against the actual device cache whenever the panel opens.
- "Pause" aborts current requests; "Resume" skips already cached tile files.
- The download UI is a small independent panel; we can restyle/move it when
  we build the itinerary interface.
- To modify tile assets, regenerate tile-index.json and verify offline again.
